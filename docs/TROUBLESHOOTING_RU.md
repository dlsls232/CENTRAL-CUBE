# Устранение неполадок

| Симптом | Возможная причина |
|---|---|
| TCP refused | Агент не запущен, неверный порт, локальный firewall |
| Тайм-аут | Маршрут, NAT/CGNAT, firewall провайдера, неверный адрес |
| TLS handshake error | Сертификат/ключ/CA не соответствуют либо отсутствует клиентский сертификат |
| TCP доступен, команды не работают | Контроллерский TLS-клиент в этой версии отсутствует |
| IPv4 недоступен извне | CGNAT или нет проброса порта |
| IPv6 недоступен | Нет глобального адреса или блокирует firewall |

Не отключайте firewall целиком. Проверяйте только конкретный TCP-порт и адрес источника.

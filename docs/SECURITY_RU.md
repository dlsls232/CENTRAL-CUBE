# Модель безопасности и ограничения

## Реализовано в 0.1.4

- TLS 1.2 минимум; агент требует клиентский сертификат, подписанный указанной CA.
- Контроллер проверяет цепочку CA и SHA-256 fingerprint сертификата агента.
- Одноразовый код сопряжения (6 цифр, 300 секунд, максимум 5 неудачных попыток) принимается только по mTLS; после успешной проверки fingerprint клиента атомарно записывается в JSON allowlist.
- Агент дополнительно сверяет SHA-256 fingerprint клиентского сертификата с обязательным JSON allowlist; без совпадения запрос не обрабатывается.
- Точечный отзыв клиентского сертификата выполняется удалением fingerprint из allowlist и перезапуском агента.
- Команды ограничены allowlist: `ping`, `system_info`, `shutdown`, `restart`, `sleep`.
- Power actions выключены по умолчанию; при включении требуется `confirmed=true` и пользовательское подтверждение в GUI.
- Размер JSON frame ограничен 1 MiB; агент ограничивает ожидание запроса 15 секундами.
- Повторные command ID атомарно резервируются в SQLite до выполнения команды; последние 100 000 ID сохраняются между перезапусками. Параллельные запросы с одинаковым ID не могут оба пройти резервирование.
- Агент пишет JSONL audit log; контроллер пишет историю в SQLite.

## Не реализовано / требуется до production

- Автоматическая выдача клиентских сертификатов; сертификат контроллера предварительно выпускается внешней PKI. Одноразовое сетевое pairing по коду уже реализовано.
- CRL/OCSP; изменение allowlist требует перезапуска агента.
- Персистентный anti-replay store между перезапусками.
- Защищённое хранилище приватных ключей через Windows DPAPI/Credential Manager; приложение сохраняет только пути к PEM-файлам.
- Ротация и защита audit log, ограничение привилегий агента и Windows Service hardening.
- Полный Windows QA, аудит безопасности и Authenticode-подпись.

Не публикуйте агент в интернет без отдельного сетевого и security review. Прямое подключение зависит от публичного IPv4 с пробросом TCP или глобального IPv6 и firewall. CGNAT обычно исключает входящее IPv4-соединение.

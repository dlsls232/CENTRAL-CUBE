# Release Notes — CENTRAL CUBE 1.0.0

## Основные изменения

- Завершена консолидация версии проекта, package metadata, GUI, агента и Inno Setup.
- Усилена защита сетевого контура: TLS/mTLS, проверка сертификатов и fingerprint allowlist.
- Добавлена устойчивая защита от повторного выполнения `command_id` с хранением после перезапуска.
- Добавлены rate limiting, ограничения соединений/сообщений и TLS timeouts.
- Добавлен отзыв доверенного клиентского сертификата через allowlist без необходимости перезапуска для новых соединений.
- Улучшена SQLite-целостность: backup, integrity check, аудит и безопасный CSV export.
- Сетевые операции GUI перенесены в фоновые worker-задачи для снижения риска зависания интерфейса.
- Подготовлены Windows build script, Inno Setup configuration и GitHub Actions workflow.
- Добавлена русская эксплуатационная документация, архитектурное описание, инструкция обновления и troubleshooting.

## Что требует отдельного Windows QA

В текущей среде не выполнялись фактические PyInstaller/Inno Setup прогоны и ручное Windows GUI/installer QA. Конфигурации и CI подготовлены, но выпуск Windows-бинарников, подпись и smoke-тест установки должны быть подтверждены на Windows 10/11 перед распространением готового EXE/Setup.

Это ограничение относится к бинарной поставке Windows и не означает подмены результата тестирования: в архив включены исходники, тесты, сборочные конфигурации и документация.

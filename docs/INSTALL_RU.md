# Установка CENTRAL CUBE

## Запуск из исходников
1. Установите Python 3.11+ x64.
2. Создайте venv: `py -3.11 -m venv .venv`.
3. Активируйте `.venv\Scripts\Activate.ps1`.
4. Выполните `pip install -e ".[dev]"`.
5. Запустите `python -m central_cube.main`.

## Сборка и установщик
Сборка EXE выполняется на Windows командой `scripts\build_windows.bat`. После успешной сборки откройте `installer\CentralCube.iss` в Inno Setup 6. Проверяйте EXE и установщик на чистой Windows VM. В данном архиве EXE не включены, поскольку сборка на Windows не запускалась.

## Удаление
Используйте штатный деинсталлятор Windows. SQLite-файл в пользовательском каталоге данных оставляется для сохранения настроек и журнала; перед ручным удалением сделайте резервную копию.

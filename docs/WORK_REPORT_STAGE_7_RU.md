# Этап 7 — перенос сетевых операций GUI в фоновые задачи

## Выполнено
- mTLS pairing выполняется через `QThreadPool`; диалоги ввода кода и выбора сертификатов остаются в GUI-потоке.
- Удалённые команды (`ping`, `system_info`, `shutdown`, `restart`, `sleep`) выполняются в worker-потоке. Подтверждение опасных действий запрашивается до запуска сетевого запроса.
- Массовый mTLS Ping выполняется в worker-потоке; SQLite-аудит и обновление виджетов выполняются в GUI-потоке после завершения.
- Wake-on-LAN отправляет Magic Packet в worker-потоке; результат корректно помечается `sent_unconfirmed` — UDP-отправка не подтверждает включение ПК.
- Добавлен общий сбор путей CA/client certificate/private key. Пути сохраняются в настройках только после выбора всех трёх файлов.
- Ошибки pairing, удалённых команд и Wake-on-LAN записываются в журнал аудита.
- Добавлена ранняя проверка диапазона тайм-аута в `pair_with_agent` (0.1–60 секунд).
- Исправлен тестовый ресурсный leak: `with sqlite3.connect(...)` не закрывает соединение, поэтому тест backup переведён на `contextlib.closing`.

## Ограничения, оставшиеся после этапа
- Для массовых операций пока нет пользовательской отмены и индикатора прогресса по каждому устройству.
- При закрытии окна приложение ожидает завершения активных задач; сетевые тайм-ауты ограничивают длительность отдельных запросов.
- Поведение Qt-пула, диалогов и Windows packaging требует проверки на Windows 10/11.

# CENTRAL CUBE — состояние проекта 1.0.0

## Выполненные этапы

1. Полный аудит исходной версии и запуск исходных тестов.
2. Security & Identity: mTLS, anti-replay, allowlist, rate limiting, TLS timeouts и отзыв сертификатов.
3. SQLite & Data Integrity: проверка целостности, резервное копирование, аудит и безопасный CSV export.
4. GUI & UX: сетевые операции перенесены в фоновые worker-задачи.
5. Windows Agent: проверены исходный код, конфигурация, allowlist команд и сценарии автозапуска; фактический Windows runtime QA остаётся отдельной эксплуатационной проверкой.
6. Build & CI: подготовлены PyInstaller/Inno Setup/GitHub Actions конфигурации и единая версия 1.0.0.
7. Финальное тестирование в доступной среде: 53 passed, compileall успешно.

## Финальный архив

`CENTRAL_CUBE_1.0.0_FINAL.zip` содержит полный проект, тесты, документацию и сборочные файлы.

## Важное ограничение

Windows EXE/Setup не были собраны и запущены в текущей Linux-среде. Перед внешним распространением бинарников требуется выполнить подготовленный Windows QA. Не заявлять, что Windows installer smoke test уже выполнен, пока он не запущен на реальной Windows 10/11.
